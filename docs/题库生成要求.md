# 个人刷题软件题库生成要求（交给 AI 使用）

本文既是当前程序的题库数据契约，也是生成题库时可直接交给 AI 的要求。普通文字题
优先生成 UTF-8 TSV；需要图片、附件或自定义评分时生成 ZIP 题库包。CSV 仅在目标工具
不便导出 TSV 时使用。

## 一、推荐交付：UTF-8 TSV

### 1. 文件总体结构

文件扩展名为 `.tsv`，编码必须为 UTF-8。开头先写 5 行题库元数据，随后写一行表头，
再写题目。字段之间使用真正的 Tab 字符，不能用若干空格代替。

```text
# schema_version: 1
# bank_id: 由 UUID 生成器产生且以后保持不变
# name: 题库名称
# subject: 科目名称
# content_version: 1
```

正式题库必须提供 `bank_id`。程序虽可在缺失时根据题库名称和科目生成稳定 ID，但只
用于兼容临时文件；名称或科目变化后可能被识别为另一题库。更新同一题库时保持
`bank_id` 不变，并递增 `content_version`。

推荐使用以下完整表头：

```tsv
编号	年份	题型	题干	选项A	选项B	选项C	选项D	选项E	答案	解析	考点	来源	章节	Tags
```

程序最低要求存在以下列：`编号、题型、题干、选项A、选项B、答案`。其余列可以留空，
但正式学习题库应尽量完整填写。还可增加可选列 `题目ID` 和 `题目版本`；通常无需提供，
程序会根据 `bank_id + 编号` 生成稳定题目 ID，题目版本默认等于题库内容版本。

### 2. 各列要求

| 列名 | 要求 |
| --- | --- |
| 编号 | 必填；题库内唯一且长期稳定，例如 `2025-FG-001`。改题时不要改编号。 |
| 年份 | 建议填写四位年份；非真题可填“模拟”“无年份”等明确值。 |
| 题型 | 必填；写 `single`、`multiple` 或 `qa`（问答题）。程序也兼容“单选/单选题/多选/多选题/问答/问答题/简答/简答题”。 |
| 题干 | 必填；含否定词时必须保留“错误的是、不正确的是、不属于”等关键表述。 |
| 选项A—E | A、B 必须填写；其余按实际选项填写。不要在内容前重复写 `A.`。只允许 A—E。 |
| 答案 | 必填；只写大写字母。单选只能有 1 个，例如 `B`；多选按 A—E 顺序连写，例如 `ACD`。 |
| 解析 | 建议填写；说明正确依据，必要时说明错误选项错在哪里。争议、过期或口径变化必须写在这里。 |
| 考点 | 建议填写简洁、可检索的知识点名称。 |
| 来源 | 建议填写可追溯来源，例如法规名称及条款、教材章节、真题年份题号。严禁编造来源。 |
| 章节 | 建议填写稳定的章节或模块名称，供软件筛选。 |
| Tags | 多个标签用 `|` 分隔，例如 `法规|历年真题|高频`。程序也兼容中英文逗号和分号。 |
| 题目ID | 可选；如提供，必须在题库内唯一且以后保持不变，建议使用 UUID。 |
| 题目版本 | 可选；正整数。未填时采用题库 `content_version`。 |

TSV 的每道题必须占一个物理行。题干、选项和解析中不得出现 Tab 或真实换行；需要
分段时可使用简短 Markdown/HTML 表达。不要把表头重复放进数据行。

### 3. TSV 示例

以下示例中的字段之间是 Tab：

```tsv
# schema_version: 1
# bank_id: 6bb446a3-a893-4f12-88db-f0ac05f55301
# name: 示例安全法规题库
# subject: 安全生产法规
# content_version: 1
编号	年份	题型	题干	选项A	选项B	选项C	选项D	选项E	答案	解析	考点	来源	章节	Tags
DEMO-001	2025	single	下列说法中，正确的是（ ）。	说法一	说法二	说法三	说法四		B	B 符合题干所述规则；其余选项与规则不符。	示例考点	示例材料第1节	第一章	示例|单选
DEMO-002	2025	multiple	下列措施中，属于规定要求的有（ ）。	措施一	措施二	措施三	措施四		AC	A、C 符合要求；B、D 不符合适用条件。	示例考点	示例材料第2节	第一章	示例|多选
DEMO-003	2025	qa	简述本规定的适用范围。						适用于示例材料第 1 节所述的全部单位。	要点齐全即可。	示例考点	示例材料第1节	第一章	示例|问答
```

### 问答题（qa）

- 题型写 `qa`（或“问答/问答题/简答/简答题”）；选项列必须全部留空。
- “答案”列写参考答案原文（可多行文本；可以留空，留空只影响查阅不影响导入）。
- 问答题不参与判分与练习统计；练习队列不含问答题。它们出现在题库浏览、
  自定义数量组卷、空白试卷（题下留手写作答区）、答题卡问答区与解析导出中。
- 考试模式组卷时问答题排在单选、多选之后；答题卡气泡只覆盖选择题
  （行首显示试卷题号），问答题在气泡表下方留手写作答区。

## 二、CSV 格式

`.csv` 与 TSV 使用相同的元数据、列名和业务规则，编码仍为 UTF-8，分隔符改为英文
逗号。程序支持标准双引号规则：

- 字段含逗号、双引号或真实换行时，整个字段必须用英文双引号包住；
- 字段内部的一个 `"` 写成两个 `""`；
- 每条记录的列数必须与表头一致；
- 不要使用 Excel 地区设置产生的分号分隔 CSV。

示例：

```csv
# schema_version: 1
# bank_id: 6bb446a3-a893-4f12-88db-f0ac05f55301
# name: 示例安全法规题库
# subject: 安全生产法规
# content_version: 1
编号,年份,题型,题干,选项A,选项B,选项C,选项D,选项E,答案,解析,考点,来源,章节,Tags
DEMO-001,2025,single,"下列说法中，正确的是（ ）。",说法一,说法二,说法三,说法四,,B,"B 正确；A、C、D 不符合条件。",示例考点,示例材料第1节,第一章,示例|单选
```

## 三、图片题或高级题库：ZIP

需要图片、附件或非默认评分规则时，使用现有 ZIP 格式：

```text
bank-package.zip
  manifest.json
  questions.jsonl
  media/
    image-001.png
```

`manifest.json` 至少包含：

```json
{
  "schema_version": 1,
  "bank_id": "稳定且唯一的题库 UUID",
  "name": "题库名称",
  "subject": "科目",
  "content_version": 1,
  "question_count": 100,
  "questions_sha256": "questions.jsonl 文件的真实 SHA-256",
  "media_manifest": [
    {
      "path": "media/image-001.png",
      "sha256": "媒体文件的真实 SHA-256",
      "size": 12345
    }
  ]
}
```

`questions.jsonl` 每行必须是一个完整 JSON 对象，不能使用 JSON 数组，也不能跨行。
每题字段如下：

- 必填：`question_id`、`type`、`stem`、`options`、`answers`；
- 建议填写：`external_id`、`explanation`、`knowledge_point`、`source`、`year`、
  `chapter`、`tags`；
- 可选：`content_version`、`media`、`scoring_rule`；
- `type` 只允许 `single`、`multiple` 或 `qa`；`qa` 为问答题：不填写 options，
  `answers` 写参考答案文本（可省略，字符串或单元素数组）；
- `options` 是 A—E 到选项文字的对象，至少两个非空选项；
- `answers` 是字母数组，如 `["B"]` 或 `["A", "C", "D"]`；
- `media` 中的路径必须真实存在于 ZIP 中，例如 `["media/image-001.png"]`。

默认评分规则为：单选 1 分、多选 2 分、不启用部分分、错选归零、未答 0 分。需要修改
时可提供：

```json
{
  "scoring_rule": {
    "single_score": 1.0,
    "multiple_score": 2.0,
    "partial_credit": false,
    "partial_per_correct_option": 0.5,
    "wrong_option_makes_zero": true,
    "unanswered_score": 0.0
  }
}
```

哈希必须由实际文件计算，不能让 AI 猜测或随意填写。若生成环境不能创建 ZIP、计算
SHA-256 或管理媒体文件，应改为交付 TSV。

## 四、程序校验规则

出现以下任一问题会阻止导入：

- 文件不是有效 UTF-8，ZIP/JSON/CSV/TSV 无法解析，或 schema 版本不是 1；
- 缺少必需文件、元数据或必需列；
- 题库版本、题目版本无效；
- 编号或题目 ID 重复；
- 题型不是单选、多选或问答；
- 问答题填写了任何选项；
- 题干为空，或有效选项少于两个；
- 答案为空、答案不在现有选项内，或单选题有多个答案；
- CSV/TSV 某行列数与表头不一致；
- ZIP 中题目文件/媒体哈希不匹配，或题目引用的媒体不存在。

以下情况会显示警告，但仍可导入：

- 相同题干；
- 解析为空；
- 年份、章节或来源不完整；
- 扁平文件没有显式 `bank_id` 或题库名称。

## 五、内容质量要求

AI 生成题库时还必须执行以下内容检查：

1. 只根据用户给出的材料出题；材料没有依据时明确标注，不得补造法规条文、答案或来源。
2. 先识别正向题和反向题，特别检查“错误的是、不正确的是、不包括、不属于”。
3. 答案必须与解析一致；多选题必须逐项复核，不能只凭选项数量猜测。
4. 选项应互斥、同层级、语法完整，避免“以上都对”等依赖位置的答案。
5. 保留原题的争议和过期内容，在解析中标明当前口径，不擅自删除原题或偷换答案。
6. 不生成重复题干；相似考点应改变考查角度，而不是只替换少量词语。
7. 不在题干或解析中加入“作为 AI”等说明，不输出无关前言、总结或 Markdown 表格。

## 六、可直接复制给 AI 的任务指令

```text
请依据我提供的资料生成“个人刷题软件”题库。

交付格式：UTF-8 TSV。严格遵守随附的《个人刷题软件题库生成要求》：先输出 5 行 # 元数据，再输出规定表头和题目数据；字段用真正的 Tab 分隔，每题只占一个物理行。题型只用 single 或 multiple；答案只用按 A—E 排序的大写字母；编号必须唯一且稳定。不得编造材料中不存在的事实、法条、答案或来源。遇到反向题、争议题或过期题必须复核，并在解析中明确说明。

题库名称：<填写>
科目：<填写>
题库 bank_id：<首次生成 UUID；更新旧题库时填写原 ID>
题库内容版本：<填写正整数>
出题范围和数量：<填写>

生成完成后自行检查：列数一致、编号唯一、题型合法、A/B 至少非空、答案不越界、单选仅一个答案、多选答案已排序、答案与解析一致、来源可追溯。最终只交付题库文件内容和检查结果，不要添加与题库无关的说明。
```
