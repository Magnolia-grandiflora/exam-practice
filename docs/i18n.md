# 国际化（i18n）说明

实施日期：2026-09-11。首批语言：**简体中文（zh，模板语言）** 与 **English（en）**。
技术方案：Flutter 官方 `flutter_localizations` + ARB + gen-l10n，不引入任何第三方状态管理或路由库。

## 1. 架构与文件

| 文件 | 作用 |
| --- | --- |
| `l10n.yaml` | gen-l10n 配置：模板 `lib/l10n/app_zh.arb`，输出到 `lib/l10n/generated/` |
| `lib/l10n/app_zh.arb` | 中文模板（唯一事实来源，占位符元数据在此维护） |
| `lib/l10n/app_en.arb` | 英文翻译（键集必须与模板一致，gen-l10n 会校验） |
| `lib/l10n/generated/` | 生成物（**已 gitignore**，`flutter pub get` / `flutter gen-l10n` 自动再生成） |
| `lib/l10n/fragments/` | 并行迁移时的键片段（合并进主 ARB 后可删除） |

工具链命令：

```powershell
flutter gen-l10n                                  # 手动生成（平时 pub get 已自动触发）
python tool/merge_l10n_fragments.py               # 把 fragments/*.json 合并进两个主 ARB（幂等、冲突即报错）
```

## 2. 代码用法

```dart
import '../l10n/generated/app_localizations.dart';

final l10n = AppLocalizations.of(context)!;   // of() 可空，MaterialsApp 已注入委托，实际恒非空
Text(l10n.commonCancel);
Text(l10n.exitPendingTitle(pending));          // 占位符即参数
```

`MaterialApp`（`lib/main.dart`）已接入：

- `localizationsDelegates: AppLocalizations.localizationsDelegates`（含 Material/Widgets/Cupertino 全局委托）；
- `supportedLocales: AppLocalizations.supportedLocales`（zh、en）；
- `locale: _resolveLocale(controller.localeTag)`。

## 3. 语言偏好与切换

- 偏好存储在 `app_settings` 表键 `locale_tag`（`'system' | 'zh' | 'en'`），由
  `AppController.localeTag` / `setLocaleTag()` 管理，**仅本地保存，不参与云同步**（`syncScope: 'local'`）。
- 设置页"同步与备份/外观"区域提供语言选择：跟随系统 / 简体中文 / English；切换即时生效（无需重启）。
- `system` 时由 Flutter 按系统语言在受支持列表中解析；系统语言非 zh/en 时回退到 zh（列表首选语言）。

## 4. 导出与打印的语言规则（明确约定）

- 试卷、答题卡、解析、回顾、错题集等 **Markdown/PDF 导出的标签随导出时的界面语言**生成；
- 题干、选项、解析、用户笔记、题库名等**题目内容保持原文，永不翻译**（不接入任何机器翻译）；
- 已存在的历史导出文件不做批量重写；
- 作答事件、同步 JSON 键、数据库列名、内部枚举值（如事件来源 `paper_omr_scan`）不受 i18n 影响。

## 5. 边界说明

- Windows 原生窗口/文件选择对话框由操作系统绘制，其语言跟随系统语言，应用不控制；
- 代码注释保持中文（面向维护者，非用户可见面）；
- 服务层抛出的异常 `toString()` 保留技术诊断文本（日志用）；用户可见的错误经错误码映射为本地化文案
  （见 `lib/ui/error_messages.dart` 与服务层异常的 `code`/`params` 字段）。

## 6. 新增文案的工作流

1. 在 `app_zh.arb` 加键与中文值；含占位符时在模板加 `@key` 元数据（ICU 语法，支持 plural）。
2. 在 `app_en.arb` 加同键英文；两文件键集不一致时 gen-l10n 报错（缺失即检查，无需额外工具）。
3. 运行 `flutter gen-l10n`（或 `pub get`），在代码中通过 `l10n.键名` 使用。
4. 命名约定：camelCase，按功能前缀分组（`common*`、`shell*`、`paper*`、`practice*`、`question*`、
   `omr*`、`banks*`、`settings*`、`sync*`、`stats*`、`dashboard*`、`import*`、`exit*`、`startup*`）。

## 7. 验证

- gen-l10n 自带校验：翻译缺失、占位符类型不一致会在生成期报错；
- `flutter analyze` + `flutter test` 全量回归（UI 测试已随迁移更新为经 `AppLocalizations` 断言）；
- 语言切换持久化测试与双语文案检查见 `docs/validation.md` 对应记录。
