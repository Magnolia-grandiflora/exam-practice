# 题序 · Exam Practice：命名与图标设计

## 定位与名称

围绕大量历年真题和教辅题库开展练习的离线优先备考工具。通过覆盖未见题、回顾错题与自定义组卷，让积累的题目得到有顺序的使用。

- **中文名：题序**。“题”对应题库，“序”对应练习和复习的顺序。
- **英文名：Exam Practice**。直接表达“考试练习”，英语使用者无需理解中文拼音即可了解用途。
- **中文短介绍：把历年真题和教辅题目，整理成有顺序的日常练习。**
- **英文短介绍：Turn past papers and study-guide questions into a structured practice routine.**

英文名采用易懂的描述性表达，品牌辨识主要通过中文名和图标建立。尚未进行商标或同名产品检索。应用内显示名已更新为“题序 / Exam Practice”，发行包使用 ExamPractice 前缀；应用包标识、EXE 内部文件名及数据目录保持兼容。

## 已采用的图标资源

用户提供的两张 PNG 原图保存在 `docs/assets/icon-foreground.png`（透明版）和 `docs/assets/icon.png`（带底色版）。透明版用于 Windows ICO，带底色版用于 Android 启动图标及 README 展示。原图只做尺寸和编码转换，没有重新绘制。

在仓库根目录运行 `dart run tool/generate_app_icons.dart` 可重新生成 Windows 的 16/24/32/48/64/128/256 像素 ICO 和 Android 的 48/72/96/144/192 像素 PNG。原来未使用的 `app_icon_1.ico` 已删除。

## 图标理念：叠页上的练习进度

**两张错位的试卷，前页排列三行简化题目标记。**

后页露出少量边缘，表示积累的真题与教辅资料。前页每行由一个圆点和一条短横线构成，形成有序题目列表。前两个圆点为青绿色，最后一个为琥珀色，表示当前练习或待回顾的题目。

只使用“叠页”和“有序题目标记”两个主要元素。风格清晰、专注、稳当，适合作为长期使用的学习工具图标。

| 元素 | 要求 |
| --- | --- |
| 背景 | 青绿色 `#0D746A`，呼应应用现有主色 |
| 前页 | 暖白色 `#F7F8F2`，轻微圆角，形状厚实 |
| 后页 | 浅青色 `#B7DCD3`，向左上偏移，只露少量边缘 |
| 题目标记 | 青绿圆点与短线，最后一个圆点为琥珀色 `#E6AD45` |
| 构图 | 正方形，主体居中，四周约 20% 留白 |
| 细节 | 粗线、大间距，32 × 32 像素仍能辨认 |
| 文字 | 图标中不放文字，需要字标时单独排列名称 |

不使用相机或扫描框作为主体，避免让人误以为是扫描软件。也不叠加对勾、循环箭头、奖杯、桂冠、学士帽、火箭、机器人或大脑。

## 可直接交给绘图 AI 的提示词

> 为一个名为“题序 / Exam Practice”的开源备考刷题应用设计应用图标。它将大量历年真题和教辅习题整理为个人题库，支持按顺序练习、回顾错题和组卷检验。用简洁、克制、几何化的平面图形表达这个概念。
>
> 正方形画布，纯青绿色背景 #0D746A。中央为两张稍微错位叠放的试卷：后页为浅青色 #B7DCD3，向左上偏移，只露出少量边缘；前页为暖白色 #F7F8F2，形状厚实，边角轻微圆润。前页仅有三行简化题目标记，每行由左侧圆点和右侧短横线构成，排列整齐，间距宽松。前两个圆点为青绿色实心点，最后一个圆点为琥珀色 #E6AD45，代表当前练习或待回顾的题目。短横线使用青绿色，粗细清晰。
>
> 整体居中，四周留约 20% 安全空间，适合 Windows 和 Android 应用图标，可适应圆形或圆角方形裁切。缩小到 32 像素时，仍能读出叠放纸页和有序题目的整体形状。采用干净的矢量风格边缘、纯色填充，不做写实纸张纹理。
>
> 只输出单个图标，不要手机样机、桌面场景、宣传海报或多图拼贴。不要文字、字母、数字、水印、书法、对勾、环形箭头、奖杯、桂冠、学士帽、火箭、机器人、大脑、相机或扫描框。不要 3D、玻璃质感、金属效果、复杂渐变或强烈投影。输出 1024 × 1024 高清 PNG。

## 建议索取的文件

1. 青绿背景的完整方形图标：1024 × 1024 PNG，由平台处理最终裁切。
2. 同一主体的透明背景 PNG：便于制作 Android 自适应图标前景。
3. 单色版本：检查轮廓与小尺寸辨识度。
4. 若支持真正的矢量输出，附 SVG；仅将 PNG 嵌入 SVG 不算矢量稿。

选稿时检查 32 × 32 和 48 × 48 缩略图：纸页边缘不要混在一起，三行不要挤成一团，琥珀色圆点不要压过主体。生成大图后仍需转换为各平台图标资源；Android 前景和背景需分层制作。
